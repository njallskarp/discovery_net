# Analytic Estimates Approach

Use analytic reasoning as the primary source of the result. Computation may test constants or boundary cases, but it should not substitute for the uniform estimate.

## Working mode

- Identify the quantity to bound and the scale on which the desired conclusion becomes true.
- Derive exact identities before introducing inequalities.
- Track where constants and losses enter; distinguish qualitative from quantitative sufficiency.
- Test extremal and equality cases before optimizing constants.
- Prefer estimates stable across the intended parameter range over bounds fitted to observed data.
- When using asymptotics, state uniformity, error terms, and the threshold where the result applies.
- When using transforms or generating functions, justify convergence, inversion, coefficient extraction, and exchanges of limits or sums.

Seek a reusable inequality, monotonicity principle, stability estimate, or asymptotic lemma rather than a numerical fit.

## Pivot condition

If repeated estimates lose exactly the quantity needed for the theorem, isolate the sharp obstruction. Return either a proved barrier or a precise lemma another method must supply; do not hide the loss behind larger computation.

Report the decisive identity, each nontrivial estimate, constants, equality cases, and remaining analytic gap.
