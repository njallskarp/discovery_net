# Principal Research Report

Use this structure unless the invoking prompt requests another format.

## 1. Executive recommendation

State the portfolio-level conclusion first:

- Agents to leave uninterrupted.
- Agents that should change approach.
- Agents that should change problem.
- Agents that should coordinate, pause, or be reassigned.
- The most important uncertainty affecting these calls.

## 2. Team portfolio

Use a comparison table with these columns when the roster is large enough to benefit:

| Agent | Problem and field | Current target | Primary approach | Tools | Cumulative advancement | Recent return | Novelty | Publishability | Importance | Overlap or collaboration | Recommendation | Confidence |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

Keep cumulative advancement and recent return separate. A historically strong agent may currently be diminishing; a new agent may have little cumulative output but high option value.

## 3. Overlap and coverage

Report:

- Concentration by field and problem.
- Concentration by mathematical approach.
- Concentration by tooling or common trust base.
- Harmful duplication.
- Beneficial independent verification.
- Complementary dependency chains.
- Important fields, approaches, or proof obligations absent from the team.

## 4. Most novel efforts so far

Rank only substantive results:

| Rank | Effort or artifact | Agent | Novelty evidence | Publishability | Importance | Verification and caveat |
|---|---|---|---|---|---|---|

Use separate judgments rather than one opaque overall score.

## 5. Agent decisions

For each recommended change, state:

- Current lane.
- Proposed action.
- Evidence and expected benefit.
- Main risk or opportunity cost.
- Reevaluation milestone or deadline.

## 6. Opportunity queue

Provide two to five ordered entries:

| Priority | Opportunity | Best-fit agent profile | Selector + approach + tools | First milestone | Likely payoff | Stop or pivot condition |
|---|---|---|---|---|---|---|

The queue may contain a concrete problem, an approach pivot, a graph target, a generalization, or an instruction to run literature-first problem discovery.

## 7. Evidence gaps

List missing information that could change the ranking: absent recent turns, uncommitted artifacts, unresolved reviews, unclear authorship, incomplete literature checks, hidden resource costs, or uncertain team membership.

## Optional ordinal anchors

Use these only when scoring helps the comparison.

### Novelty

- **1:** duplicate, classical, or unsupported novelty claim.
- **2:** modest variation or graph-new result with substantial prior-art uncertainty.
- **3:** apparently new intermediate result with a targeted literature search.
- **4:** strong search-relative novelty with a new mechanism, classification, or meaningful bound.
- **5:** compelling literature-supported novelty with broad or central consequences.

### Publishability

- **1:** no precise or validated mathematical result.
- **2:** useful observation but major proof, novelty, or reproducibility gaps.
- **3:** rigorous intermediate result requiring positioning or exposition.
- **4:** self-contained result with strong reproducibility and plausible venue fit.
- **5:** externally review-ready work with resolved prior art, clear importance, and robust verification.

### Importance

- **1:** narrow result with little demonstrated leverage.
- **2:** useful locally but limited downstream consequence.
- **3:** meaningful progress on an active program or reusable technical contribution.
- **4:** substantial advance on an important problem or broadly reusable method.
- **5:** central frontier advance or result with major transfer potential.

### Recent return

- **1:** no substantive recent mathematics or purely operational activity.
- **2:** incremental progress, scaffolding, or repeated extension without a new mechanism.
- **3:** useful lemma, certificate, counterexample, or validated reduction.
- **4:** material strengthening, generalization, closure, or new proof mechanism.
- **5:** exceptional recent advance that changes the state or direction of the problem.

Scores are evidence summaries, not measurements. Report uncertainty and avoid arithmetic aggregation unless the invoking prompt supplies explicit weights.
